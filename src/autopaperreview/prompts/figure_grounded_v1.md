Inspect every numbered figure and table graphic from the original PDF page image. Do not review figures from `manuscript.txt` captions alone.

For each Figure N / Table N graphic:

1. Inventory: id, PDF page, and what is drawn (scatter, bar, architecture diagram, qualitative photo, overlay, heatmap).
2. Visible marks: axis names and units, legend entries, error bars, sample sizes drawn on the plot, highlighted regions, photo content.
3. Caption vs ink: name any caption claim that is not visible, and any visible mark the caption does not mention.
4. Body citations: for each sentence that cites this figure, say whether the ink supports it.
5. Contradictions with equations, tables, or other figures.

Rules:

- A finding that only restates the caption is not evidence that the figure was read. Cite at least one visible mark that is not in the caption.
- Location must be `Figure N, page P` or `Table N, page P`.
- Do not infer scientific facts that are not visible on the page (no imagined error bars, no imagined robot metrics).
- Do not skip qualitative teaser photos, method cartoons, or "illustration" panels: those are often the only support for a deployment or capability claim.
- Return schema-valid review issues bound to evidence IDs. Do not return free-form prose as the only result.
